# DevOps Assignment 3 - Python Programs

## Introduction

This repository contains my work for **DevOps Assignment 3**.

The assignment consists of 20 common Python programming problems. Each problem has been implemented as a Python function in the `Code` folder and tested using Python `assert` statements in the `Test_Code` folder.
